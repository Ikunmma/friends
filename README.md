### 无言の小屋动态友链

- 友链数据会由 GitHub Issues 自动生成，博客页面无需手动修改。
- 友链按最近一篇文章的发布时间倒序排列，越活跃的站点越靠前。
- 系统每天检查站点是否可以访问，并读取申请者提供的 RSS/Atom 地址。
- 没有订阅地址的站点仍可展示，但不会显示最新文章。

### 自助友链申请流程

1. 使用 Issue 模板提交申请并如实填写站点资料。
2. 等待站长审核；审核通过时会移除“审核中”标签。
3. 稍等片刻，自动任务会把站点和最新文章更新到博客友链页。

### 如何提交意向申请？

按照 [Issue 模板](https://github.com/Ikunmma/friends/issues/new/choose) 填写并提交。资料发生变化时，直接修改原 Issue 即可。
